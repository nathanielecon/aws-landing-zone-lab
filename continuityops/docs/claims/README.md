# ContinuityOps claims boundary

## Allowed after Phase 0 only

- Repository authority scaffold exists for ContinuityOps
- Upstream Project A pin recorded; Project C digest explicitly unavailable
- Unauthorized Phase 1 execution is rejected while `execution_approved` is false

## Not allowed

- Live EKS / Lambda / restore / cost claims
- Multi-account production Landing Zone claims inherited from Project A design
- Project C production release provenance without digest pin
- Azure networking depth without separate authorization and evidence
