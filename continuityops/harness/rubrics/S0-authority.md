# ContinuityOps S0 rubric — authority and orchestration

Status: `active`

## Must-haves

1. All ContinuityOps paths stay under `continuityops/`.
2. Project A and Project C are not edited.
3. Human gates are disabled while building.
4. Orchestration model defines Stage 1 build then Stage 2 multi-threaded
   accuracy loops with stop score ≥ 9.5.
5. Partition manifest assigns each path one primary slice.
6. Recruiter artifacts English; worker handoffs Simplified Chinese.
